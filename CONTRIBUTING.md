# Contributing to SimpleSQL

Thanks for contributing.

## Development setup

1. Install Node.js 20+
2. Install dependencies from repo root:

```bash
npm install
```

3. Install dependencies for workspaces if needed:

```bash
npm run install:all
```

4. Start development:

```bash
npm run dev
```

## Pull request guidelines

- Keep changes focused and small.
- Include clear PR titles and descriptions.
- Reference related issues.
- Update docs if behavior changes.
- Do not commit secrets, tokens, or local credentials.

## Code style

- Follow existing TypeScript and React patterns in the repo.
- Avoid unrelated refactors.
- Keep naming explicit and readable.

## Reporting bugs

Please include:

- What you expected
- What happened
- Reproduction steps
- OS and version
- App version / commit hash
